# Video Idea Tournament Workflow

Purpose: prevent the system from polishing weak ideas. Scripts are a prize, not a default output.

## Round 1: Generate 50 raw ideas
Generate from different agent groups:
- 10 customer-insight tensions
- 10 TikTok/content angles
- 10 entertainment mechanisms
- 10 paid/conversion angles
- 10 founder/UGC/community angles

Raw ideas should be one-line concepts only. No scripts.

## Round 2: Reject 30 immediately
Reject with short reasons. Kill ideas that are generic, claim-heavy, AI-first, not filmable, not gym-native, or reducible to “your pre should match your workout.”

## Round 3: Improve remaining 20 through the council
For each remaining idea, run the stages in `multi-agent-video-council.md`. Add:
- Target viewer
- Emotional trigger
- Entertainment mechanism
- Production plan
- Sales reason
- Brand/trust fix
- Claim-safety fix

## Round 4: Reject 10 more
Reject the 10 weakest after council improvement. Reasons must be specific: weak first frame, unclear product logic, too lecture-like, bad sales purpose, low comment potential, claim risk, or not filmable this week.

## Round 5: Score remaining 10
Use `video-idea-scoring-rubric.md`. Hard gates apply before total score.

## Round 6: Select top 5
Select by score and strategic variety. Do not select five versions of the same “workout match” idea.

## Round 7: Create full scripts only for top 3
Scripts are allowed only for top 3. Each top idea must include:
- Original raw idea
- Criticism from at least four agent perspectives
- Revised idea
- Final reason it survived
- Hook
- 0–15 second timeline
- Script
- Shot list
- Overlays
- Caption
- CTA
- Comment-bait line
- Claim-safety notes

## Round 8: Create filming packets only if recommended this week
A filming packet is created only if the idea is filmable this week and beats the hard gates. If not, hold it as a future concept.

## Anti-polish rule
Never write a beautiful script for a weak premise. If an idea has weak tension, weak mechanism, or weak sales logic, kill it before scripting.
