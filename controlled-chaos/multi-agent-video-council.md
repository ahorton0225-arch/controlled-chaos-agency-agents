# Multi-Agent Video Idea Council

Purpose: turn Controlled Chaos product truths into video ideas that survive audience insight, entertainment, production, conversion, brand, compliance, and reality pressure. This is a sequential council, not a one-shot generator.

## Operating principle
Do not ask every agent to do everything. Each pass has a job. The council must create disagreement before synthesis. If an idea reduces to “your pre should match your workout,” it fails unless the entertainment mechanism, audience tension, and sales logic make that truth feel new.

## Stage 1: Input Intake
Accept:
- Customer objection
- Customer comment
- Founder belief
- Competitor ad
- TikTok trend
- Gym culture truth
- Product angle
- Creator example
- Sales problem
- Website objection
- Real customer situation

Minimum accepted input: one customer tension, one product truth, one filming constraint, and one banned direction.

## Stage 2: Customer Insight Pass
Use Customer Insight Agents from `full-agent-capability-map.md`. Extract:
- Target viewer
- Emotional trigger
- Hidden frustration
- Identity/status angle
- Objection
- Belief to challenge
- What would make someone comment
- What would make someone share
- What would make someone buy

Output only insights and tensions. Do not create scripts yet.

## Stage 3: Creative Strategy Pass
Use Creative Strategy Agents. Generate:
- Possible angles
- Platform fit
- Hook territories
- Paid vs organic potential
- Founder-led version
- UGC version
- Influencer version
- Content series potential

Reject angles that are only claims, taglines, or explanations.

## Stage 4: Entertainment Mechanism Pass
Use Entertainment/Format Agents. Transform each angle into one or more mechanisms:
- Skit
- Game
- Debate
- Street interview
- Challenge
- Roast
- Tier list
- Public test
- Fake expert panel
- Gym argument
- Visual analogy
- Creator prompt
- Comment-driven series

No idea can pass this stage unless it has a visible mechanism with a scene, conflict, or audience action.

## Stage 5: Production Feasibility Pass
Use Production Agents. Check:
- Can this be filmed with a phone?
- Can this be filmed by one person?
- Can this be filmed in a gym or bedroom?
- Does it need actors?
- Does it need advanced editing?
- Does it have a clear first frame?
- Does it have obvious shots?
- Can it be filmed this week?

If not filmable, simplify the mechanism before it moves forward.

## Stage 6: Sales/Conversion Pass
Use Conversion/Sales Agents. Check:
- Does this make Controlled Chaos easier to understand?
- Does it show why the quiz/formula matters?
- Does it create a reason to click?
- Does it overcome an objection?
- Does it make the product feel useful, not gimmicky?
- Does it avoid entertainment with no sales purpose?

Every surviving idea must state the missing question that Controlled Chaos asks and generic pre-workouts do not.

## Stage 7: Brand/Trust Pass
Use Brand/Trust Agents. Check:
- Does it sound like Controlled Chaos?
- Does it sound like gym culture, not corporate marketing?
- Does it avoid fake AI hype?
- Does it avoid cringe founder content?
- Does it fit black/red/gunmetal/premium/intense brand energy?

Rewrite any line that sounds like “unlock,” “revolutionary,” “game changer,” “fuel your journey,” “next level,” or “personalized for you.”

## Stage 8: Compliance/Risk Pass
Use Compliance/Risk Agents. Check:
- No guaranteed PRs
- No fat-loss claims
- No medical claims
- No universal stimulant safety claims
- No exaggerated ingredient claims
- No “this will make you” language
- Only safe phrasing: “designed for,” “built around,” “supports,” “prioritizes,” and “based on your inputs”

If the product truth needs substantiation and none is supplied, rephrase or cut it.

## Stage 9: Reality Checker Pass
Use Reality/QA Agents. Brutally reject ideas that are:
- Generic
- Lecture-like
- Too close to supplement ads
- Not scroll-stopping
- Not filmable
- Not funny, useful, surprising, or tension-based
- Too reliant on “custom pre-workout”
- Usable by any supplement brand unchanged
- Good as product explanation but bad as TikTok

Reality Checker has veto power.

## Stage 10: Final Synthesis
Only after survival, create:
- Hook
- Title
- Concept
- Script
- Shot list
- Overlays
- Caption
- CTA
- Comment-bait line
- UGC version
- Founder version
- Paid-ad version

Final synthesis must include the raw idea, at least four agent criticisms, revised idea, final score, and reason it survived.
