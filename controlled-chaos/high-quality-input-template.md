# High-Quality Input Template

Use this before running the video council. Better inputs create better ideas.

## Required inputs
- **Goal:** views / comments / sales / awareness / explanation / influencer / paid ad
- **Target customer:** age, training style, split, identity, pain, buying stage
- **Customer objection:** exact words if possible
- **Customer comment:** paste real comment/review/DM if available
- **Gym culture truth:** what lifters believe, joke about, argue about, or hide
- **Product truth:** what Controlled Chaos actually does differently
- **Founder belief:** strong point of view, not a slogan
- **Competitor/reference example:** paste description or link summary
- **What I like about the example:** pacing, format, conflict, comments, visuals, creator energy
- **What I hate about current ideas:** generic angle, fake AI, corny tone, unsupported claims, hard to film
- **Filming constraints:** phone, one person, gym, bedroom, car, dorm, whiteboard/cards, product tub, quiz screen
- **Props available:** list actual props
- **Location available:** gym, garage, dorm, office, supplement shelf, parking lot
- **Tone preference:** funny / intense / founder-direct / skeptical / debate / roast / premium / educational
- **Banned ideas:** phrases or angles that must not appear
- **CTA:** comment, take quiz, build formula, DM, click, join waitlist
- **Offer/discount if relevant:** code, bundle, sample, creator code, deadline

## Optional strengtheners
- A real customer profile
- A failed ad and why it failed
- A winning post and why it worked
- A product limitation that must not be overclaimed
- A compliance phrase that must be used

## Minimum viable input
If short on time, provide: goal, target customer, objection, gym culture truth, product truth, filming constraints, banned ideas, and CTA.
