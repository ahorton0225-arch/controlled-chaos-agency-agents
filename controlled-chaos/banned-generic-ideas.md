
# Banned Generic Ideas

## Banned as standalone ideas
- “You are using the wrong pre-workout.”
- “Stop using generic pre-workout.”
- “Your pre should match your workout.”
- “Take the quiz.”
- “AI made my pre-workout.”
- “This is personalized for you.”
- “This pre-workout is different.”

## Allowed only when transformed
These angles are allowed only if converted into a specific creative mechanism: courtroom trial, fantasy draft, NPC skit, founder experiment, blind taste/performance test, whiteboard breakdown, locker-room debate, tier list, audit, game loadout screen, or street interview.

## Rejection checklist
Reject the output if it:
- Could be used by any supplement brand after changing the logo.
- Has no named setting, character, conflict, or visual device.
- Says “AI-powered” without showing what AI changes.
- Has a hook that explains instead of interrupts.
- Requires production resources beyond phone, gym, tub, paper/whiteboard, laptop, or basic editing.
- Makes aggressive unsupported claims.
