
# Controlled Chaos Workflow Layer

This folder adapts the existing `agency-agents` library into a Controlled Chaos company command system. It is **not** a full app, dashboard, formula engine, ecommerce build, or rewrite of the original agent library. It is a workflow and prompt layer for using the repo today.

## How to use it
1. Start with `brand-profile.md` and `target-customer.md` as the permanent context.
2. Use `agent-map.md` to choose the best existing repo agents for the job.
3. Use a workflow file such as `ad-creation-workflow.md`, `website-audit-workflow.md`, `outreach-workflow.md`, or `operations-workflow.md`.
4. Run output through `reality-checker-workflow.md` before filming, publishing, sending, or building.

## What this layer does
- Turns the general-purpose agency-agent catalog into Controlled Chaos-specific teams.
- Forces marketing ideas to be specific, visual, executable, and gym-native.
- Preserves the original repo while adding a company-specific operating layer.

## What it does not do yet
- No new app.
- No dependencies.
- No ecommerce or quiz implementation.
- No formula recommendation engine.
- No replacement of original agents.
