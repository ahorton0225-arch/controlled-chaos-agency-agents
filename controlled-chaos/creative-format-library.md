# Creative Format Library

Reusable formats for Controlled Chaos. Each idea must use a mechanism like these, not a naked claim.

## 1. Ingredient Fantasy Draft
- **What it is:** A short-form concept built around ingredient fantasy draft as the visible scene or editing device.
- **Why it works:** It gives the viewer a specific conflict, pattern interrupt, and commentable premise instead of a generic supplement claim.
- **Controlled Chaos use:** Use the format to show how training style, split, goals, caffeine tolerance, pump, focus, endurance, or taste preferences change the formula recommendation.
- **Difficulty:** medium
